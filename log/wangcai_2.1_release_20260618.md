# Wangcai 2.1 Release Notes

发布日期：2026-06-18

## 版本定位

Wangcai 2.1 在 2.0 图文创作链路基础上，加入固定角色库和成果小剧场能力。2.0 解决“旺财能画图、成果能图文并茂”的问题；2.1 进一步解决“长期作品里角色可以稳定复用、持续成长、按语义召回”的问题。

## 核心更新

- 新增角色库页面：从成果库进入，可创建、修改、删除角色，并维护头像、参考照片、人物设定、绘图 prompt、关系和成果小剧场指令。
- 新增角色库专用聊天：角色编辑、补全设定、生成头像/照片/场景图都集中在角色库完成；普通聊天和分析模式不再随机改写角色库。
- 新增全局角色记忆：固定角色同步为 `characters` 类型的 global embedding 索引，供聊天、绘图和成果小剧场按语义召回；不混入个人用户记忆列表。
- 新增角色场景图：角色库可以生成多角色同框、对战、相遇或剧情片段，并把图片绑定到参与角色。
- 强化成果小剧场：成果生成可参考固定角色、角色关系和导演指令，减少长期作品中角色漂移。
- 优化角色库 UI：角色卡片图片条、摘要、标签、删除/下载、头像生成和移动端布局多轮调整，避免遮挡和溢出。
- 优化记忆后台：角色创建和修改不再写成 anonymous event；记忆管理页把新增时间作为标签展示。
- 优化分析模式：后台 trace 标题继续中文化，`memory_query_planner` 显示为“记忆检索规划”，移动端 trace 固定在聊天内容下方。
- 优化模型配置：补充常见供应商模型预设，并支持全局保存供应商级 API key 状态和联网代理配置。

## 发布边界

本次 GitHub 发布只包含代码、静态资源、公开 README 和 release log。以下内容不上传：

- 生成角色图片、头像、场景图和本地成果图片。
- 聊天数据库、成果数据库、角色库运行期数据库、记忆数据库。
- 服务日志、模型日志、调试日志、运行 PID。
- 私有 prompt、故事种子、代理地址、API key、token 和本地环境配置。
- Codex 开发用 docs、tests、tools 和一次性维护脚本。

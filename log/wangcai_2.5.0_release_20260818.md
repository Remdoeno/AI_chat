# Wangcai 2.5.0

发布日期：2026-08-18

## 主要更新

- 普通记忆库继续使用共享用户密码，只显示当前用户的记忆。
- 长按主页“记忆库”会打开管理员密码验证，验证后进入全局记忆后台。
- 管理员记忆接口不再继承当前共享用户范围，可查看、创建、修改和删除全局记忆。
- 全局记忆后台新增共享用户列表，显示用户记忆数量和绑定设备数量；选择用户后以高亮状态筛选该用户全部绑定设备下的记忆。
- 记忆条目增加所属共享用户标识，同时保留设备身份的精确筛选能力。

## 安全边界

- 共享用户密码不能调用管理员记忆接口。
- 管理员密码不替代普通用户密码；个人分析模式和个人记忆库仍按共享用户隔离。

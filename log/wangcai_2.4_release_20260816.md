# Wangcai 2.4 Stable Release Notes

发布日期：2026-08-16

## 版本定位

Wangcai 2.4 固定了当前生产环境中已经运行的多用户隔离、公共成果库、互动新手教程和后台稳定性改进。版本重点仍然是长期陪伴体验：让不同用户拥有清晰的数据边界，同时降低初次配置和理解系统能力的门槛。

## 核心更新

- 新增共享用户密码：每个共享用户可以设置独立密码，分析模式、记忆库、成果库和角色库按用户验证与隔离；管理员密码继续保护全局后台。
- 完成成果与角色隔离：历史成果和角色资料归属明确的共享用户，角色视觉锚点与创作资料独立于用户长期记忆，避免跨用户混用。
- 新增公共成果库：作者可以把作品设为精选并公开；其他已绑定用户可以浏览、点赞和评论，但不能删除或修改原作。
- 新增桌面端互动教程：新设备首次进入时自动引导，老用户可以手动重开；教程覆盖用户绑定、模型配置、主动开场、聊天、成果、角色库、分析模式和记忆库。
- 增加教程沙盒：教程聊天、演示成果和相关临时数据在结束或跳过后清理，不写入正式记忆、成果或角色资料；用户主动确认的绑定和模型配置仍会保留。
- 改进教程交互：教程面板可拖动并保持在前台，步骤会先要求用户完成对应点击，再继续跨页面引导；移动端明确提示使用电脑端。
- 提升成果配图与角色保真：画图链路更完整地保留角色族裔、年龄、发型、体型、面部结构、气质和关键身份特征，并限制无关角色资料进入最终生图 prompt。
- 加强图像后台稳定性：补充长期高并发和失效后台进程监测，保留对正常脉冲负载的容忍，降低图像任务堆积后拖慢服务的风险。
- 修复服务重启竞态：停止或替换后台 watchdog 时等待旧进程真正退出，避免锁尚未释放就启动新实例。
- 修复密码输入控件：统一使用单个无边框眼睛按钮显示或隐藏密码，并清理重复绑定产生的双图标。
- 更新应用版本：FastAPI 应用版本更新为 `2.4.0`，前端缓存键同步刷新。

## 发布边界

本次 GitHub 发布只包含代码、静态资源、公开 README 和 release log，不包含聊天记录、用户记忆、成果数据、角色数据、生成图片、数据库、运行日志、模型权重、密钥、代理或本地环境配置。

# 旺财1.0 Release Log

发布时间：2026-06-08

## 版本定位

旺财1.0 是公开发布基线版本，目标是把本地大模型聊天、长期记忆、联网搜索、成果沉淀和基础管理界面整理成可部署的 Web 服务。

## 主要能力

- Web 聊天：基于 FastAPI 提供主页聊天、流式输出、停止生成和 reset。
- 本地模型：默认对接 OpenAI-compatible 的 Qwen3.6 服务。
- 长期记忆：支持聊天历史、记忆片段、embedding 检索和基础召回。
- 成果库：空闲后台 agent 可以沉淀小说、设定、诗歌、剧本等文字成果。
- 联网搜索：按需读取搜索结果并纳入回答上下文。
- 基础管理：提供记忆管理、成果浏览和分析模式雏形。

## 发布边界

- 不包含模型权重、数据库、聊天记录、长期记忆、管理员密码、代理地址或本地私有配置。
- 运行日志和调试日志只保留在本地，不作为公开发布内容。

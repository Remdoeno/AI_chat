# 旺财1.4 Release Log

发布时间：2026-06-14

## 版本定位

旺财1.4 是配置与后台能力增强版本，主要围绕模型配置、记忆整理稳定性、成果生成和分析模式可观察性继续打磨。

## 主要变化

- 增强模型配置：开始整理聊天模型、后台模型、embedding 和代理等配置入口。
- 优化分析模式 trace：让完整 prompt、模型调用、记忆召回和后台任务更容易排查。
- 改进成果生成：提升 idle agent 对连续作品、系列设定和术语统一的支持。
- 改进记忆后台：减少 assistant 内容被误当作用户事实保存的情况。
- 保留用户手工调整过的主 prompt 和 idle/story 相关参数，避免工程改动回滚已有定制。

## 发布边界

- 具体开发计划、SSH 连接说明、排查脚本和测试目录不应作为公开发行内容。
- 私有故事种子、数据库、模型权重和运行日志继续排除。

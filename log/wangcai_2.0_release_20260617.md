# Wangcai 2.0 Release Log

发布时间：2026-06-17

## 版本定位

Wangcai 2.0 把旺财从文字型长期陪伴助手推进到图文创作助手。它仍然保留聊天、长期记忆、联网搜索、成果库和分析模式，同时新增完整文生图链路和图文成果工作流。

## 主要变化

- 新增聊天画图模式：主页和分析模式都可以切换到“画图”，本轮发送会进入图像生成流程。
- 接入 HiDream 图像服务：默认支持本地 `HiDream-O1-Image-Dev-2604`，并允许在模型配置中单独设置图像生成模型。
- 图像 prompt 链路：中文先翻译为英文，再由 prompt agent 判断自然语言、专业 prompt 或补充修改。
- 连续改图语义：用户说“改成黑发”“修改为男性”等补充修改时，会基于同一 session 上一次送入生图器的 optimized prompt 继续改写。
- 聊天固定四图：聊天画图默认一次生成 4 张，可在聊天历史中预览和下载。
- 图文成果：后台成果生成升级为图文流程，每篇成果至少生成一张主题配图，多图时尽量承担不同视觉主题。
- 成果展示升级：成果卡片以封面图为主视觉，详情页把图片居中穿插在正文段落之间。
- 评论图片上下文：评论涉及封面、配图、画面或构图时，回复会带上图片上下文。
- 分析模式透明化：绘图记忆路由、翻译、prompt 分类、prompt 优化和图片生成都会写入 trace。
- 记忆系统修复：记忆整理能区分用户事实、已召回记忆和 assistant_context_only，修正版是否采用会明确记录。

## 发布边界

- GitHub 不包含模型权重、图像生成输出、聊天记录、长期记忆、数据库、运行日志、代理地址或 API key。
- `docs/`、`tests/`、`tools/` 和一次性维护脚本只保留在本地或服务器开发目录，不进入公开发布仓库。

# 旺财1.6 Release Log

发布时间：2026-06-15

## 版本定位

旺财1.6 是 qwen_web2 主线整理版本，重点把早期过大的单体 `app.py` 拆分为模块化结构，并把服务器上的新目录作为后续开发基线。

## 主要变化

- 拆分单体 `app.py`：按配置、prompt、函数、路由和启动逻辑整理到 `qwen_app/`。
- 保留兼容入口：根目录 `app.py` 作为旧入口 shim，继续暴露原先单体 app 的命名空间。
- 规范页面命名：主页、记忆库、成果库和分析模式统一使用“旺财”体系，不再使用旧版本号或 Qwen 页面名。
- 整理目录：清理 qwen_web2 中无用备份，明确哪些数据、记忆、成果、日志和模型权重不进入公开仓库。
- 同步服务器基线：以服务器端 qwen_web2 为新主线，避免覆盖用户已手动修改的配置和 prompt。

## 发布边界

- `docs/`、`tests/`、`tools/` 和一次性调试脚本属于本地开发资料，不属于公开运行包。
- GitHub 发布包只保留运行 2.0 所需模块、静态资源、启动脚本、公开 README 和版本日志。

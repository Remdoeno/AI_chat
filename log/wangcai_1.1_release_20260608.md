# 旺财1.1 Release Log

发布时间：2026-06-08

## 版本定位

旺财1.1 重点完善连续使用体验，让用户可以更稳定地续接上次聊天，并改善成果与记忆在前端的基础交互。

## 主要变化

- 增加上段对话续接能力：同一浏览器设备可以加载更早 session，并把当前 session 作为旧 session 的延续。
- 改进历史加载入口，减少刷新后丢失上下文的使用成本。
- 补强成果页基础操作，包括分类、随机、分页、评论和删除等交互。
- 完善静态资源版本号，减少浏览器缓存导致的前端不更新。
- 强化记忆召回与聊天上下文拼接，避免长期记忆和近期对话互相覆盖。

## 发布边界

- 测试脚本、调试日志和开发计划只保留在本地。
- GitHub 只保留可部署代码、公开 README 和版本发布说明。

# Wangcai 2.2 Stable Release Notes

发布日期：2026-06-21

## 版本定位

Wangcai 2.2 是当前服务器 `wangcai_ai` 的稳定快照版。它不是一次大改 UI 的版本，而是把 2.1 之后在线上沉淀的成果小剧场、隐藏导演指令、后台创作约束、成果容错和发布边界正式固定为可发布状态。

## 核心更新

- 固定服务器稳定快照：公开版本对应当前 `codex/main` 上的 `wangcai_app` 拆分主线，入口 `app.py` 保持兼容加载器，FastAPI 版本号更新为 `2.2.0`。
- 强化成果小剧场导演指令：聊天中关于成果、剧情、角色出场和配图方向的要求可以沉淀为隐藏导演指令，供后续 idle 成果生成参考。
- 强化用户创作 prompt 优先级：成果页配置的创作 prompt 高于角色库、历史系列、近期避重复规则和长期导演指令；明确点名的地点、题材、角色、系列和事件必须执行。
- 新增连续作品规划约束：剧情规划 agent 会读取同一系列的主线、番外、前传、外传和起源篇，再规划标题方向、剧情节拍、出场角色、场景计划和配图方向。
- 优化成果生成容错：当后台创作模型输出不完整或损坏 JSON 时，系统会先尝试结构化修复，再用确定性兜底规则恢复标题、正文、摘要、类型和配图计划。
- 优化成果命名与篇数控制：当创作 prompt 明确要求某个系列和篇数时，保存阶段会优先采用规划结果中的 `series_title`、`episode_index` 和完结策略。
- 新增后台创作频率配置：成果库可调整 idle agent 的基础运行间隔，让后台创作节奏更可控。
- 统一生产端口约定：日常部署和健康检查按 `7777` 端口处理，避免回退到旧 `9922` Web 端口。
- 自我认知同步：旺财的自我档案补充 2.2 稳定版定位，只写高层能力边界，不写服务器路径、密钥、代理、数据库路径、session 或 system prompt。

## 发布边界

本次 GitHub 发布只包含代码、静态资源、公开 README 和 release log。以下内容不上传：

- 生成角色图片、头像、场景图和本地成果图片。
- 聊天数据库、成果数据库、角色库运行期数据库、记忆数据库。
- 服务日志、模型日志、调试日志和运行 PID。
- 私有 prompt、故事种子、代理地址、API key、token 和本地环境配置。
- Codex 开发用 docs、tests、tools 和一次性维护脚本。

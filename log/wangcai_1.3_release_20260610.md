# 旺财1.3 Release Log

发布时间：2026-06-10

## 重点更新

- 发布跨设备“记忆绑定”：多个浏览器设备可以绑定同一个共享用户 ID，共享普通记忆、事件和可选聊天记录。
- 增加主机设备语义：共享组里的普通事件和事实类记忆可归到主机设备，设备专属人设、identity、persona、preference 不跨端串用。
- 优化聊天主页和分析模式移动端布局，统一按钮、标签、气泡、时间戳和输入区对齐。
- 统一文案：Analysis mode 改为“分析模式”，“记忆”入口改为“记忆库”。
- 记忆后台改为单次管理员认证体验，减少重复输入密码。
- 更新 README 开头，强调旺财与通用云端聊天机器人相比的长期记忆、成果系统、本地化和可观察性。
- README 增加旺财1.4 TODO：统一配置界面、联网大模型 API key、embedding 模型和成果生成频率配置。

## 发布注意

- 本仓库不包含模型权重、数据库、聊天记录、记忆、日志、私有 prompt、代理地址或本地参数配置。
- 运行态文件仍由 `.gitignore` 排除：data、logs、models、.env、sqlite、pid、权重文件等。

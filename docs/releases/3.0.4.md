# 3.0.4：后台心跳日志自动整理

- 每天自动将7天以前的 idle_worker_tick / idle_worker_tick_done 明细按 UTC 日期及事件类型汇总，保留次数、首次及末次时间。
- 严格白名单，不删除聊天、记忆、业务事件、错误日志或模型调用记录。
- 每批最多1000条，批次间让出执行时间；数据库忙时延后重试。汇总和删除在同一事务内完成，重复执行不重复计数。
- 汇总保存在 event_daily_summaries；原日志列表继续展示近期明细。汇总目前不单独增加界面。
- 启动60秒后后台执行，不阻塞应用启动；不运行在线 VACUUM，释放的数据库页可被后续写入复用。
- 首次清理前使用 SQLite 在线备份；历史原始细节可从服务器私有备份检索。
- 远程两项测试通过：保留边界/业务事件/汇总计数/幂等；删除失败事务完整回滚。

回滚此功能时，撤销本版本后台维护线程及模块即可停止后续清理。已合并的明细不会随代码回滚恢复；需从备份按需提取，不能覆盖期间新增的用户数据。

此前功能见 [3.0.3](3.0.3.md)。

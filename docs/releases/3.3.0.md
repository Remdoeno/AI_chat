# 旺财 3.3.0：全站界面整理

本次以当前页面风格为基础统一控件与交互，不改模型接口、个人配置及日程数据。

1. 成果、角色、分析页面优化手机内容顺序，筛选和创作设置按需展开，角色与聊天、聊天与明细可直接切换。
2. 全站共用控件尺寸、圆角、焦点、状态样式，统一中性色，保留各区强调色和日历事件分类色。
3. 模型设置分聊天、后台、生图三个页签，连接设置折叠，保存栏固定；项目节点可折叠编辑并复用路线名称。
4. 项目横图保留独立路线，长说明按需展开，突出当前阶段；日历卡片优化字号与间距。
5. 记忆、调用、系统操作切页查看，移除强制巨高面板；新增和单条编辑折叠；中屏后台表单自适应。
6. 提升日程、卡包辅助文字对比度，扩大手机控件点击区域；支持减少动态效果偏好。
7. 统一新对话、删除、登录返回等中文文案；修复卡包太阳/月亮按钮。
8. 后台统计按时间窗口切换，失败优先，Token明细展开，取消固定巨高面板。
9. 模型设置、卡包、角色编辑增加未保存关闭保护，和日历保持一致。
10. 登录及后台加载增加网络错误恢复，保留输入和已有内容，统一状态播报与输入标签。

验证和重新评分见本轮交付报告。按用户约束未运行本地测试或自动化浏览器测试；远程进行脚本语法、资源引用与部署检查，视觉表现仍需实际设备验收。

回滚：新增界面模块按职责独立，部署前保留全部受影响文件备份。可按组件退回，无需回滚用户数据。具体回滚应在聊天中提出，不在服务内添加回滚面板。

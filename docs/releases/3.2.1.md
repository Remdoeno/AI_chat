# 3.2.1：项目阶段自动排序

- 修复新加或改期的阶段沿用添加顺序、导致较晚节点排在较早节点前的问题。
- 每条子任务路线独立排序：明确前置依赖优先，其余按开始日期或截止日期、时间排序；无日期或同时间保留相对顺序。
- 日程聊天可记录和调整前置关系；保存时拒绝循环、自引用、不存在的前置节点和跨路线依赖。
- 普通编辑保留前置关系，删除前置节点或调整路线时清除失效关联。
- 项目横图、单项连线和关联记忆共享保存后的顺序，不修改原有日期及完成状态。
- 修正已有脑计划中功率测试与大纲提交的展示顺序。

验证：远程运行阶段排序、子任务路线及项目进度测试；按用户要求不运行本地测试及自动化 UI 测试。
回滚：本版本为独立提交，可单独回滚；部署前备份代码及被调整项目的数据。

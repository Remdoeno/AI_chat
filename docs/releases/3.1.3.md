# 3.1.3 日历浏览与项目展示

- 上两周、下两周、回到今天；按所选区间加载事项、每周重复安排和节假日，真实今天不随翻页移动。
- 移除桌面点击日期重复展示的明细，手机保留日期切换浏览。
- 项目展开显示横向阶段图，阶段时间、重要节点、备注和完成状态置于同一流程中。
- 事项窗口未修改时点击背景、关闭按钮或 Escape 直接关闭；有修改时选择保存、不保存或继续编辑。
- 单项节点使用短圆角折线；跨天阶段间增加间距，跨周连线利用行间空隙。
- 按工作科研、娱乐旅行、健康、个人发展、社交关系、生活事务分色系，同一事项的横条、节点和连线一致；增加相应分类供手动选择。
- 旧事项无需数据迁移即可使用色系，论文投稿归入工作科研。
- UI 按用户约定不运行自动化测试；日历窗口接口在远程隔离环境验证。
